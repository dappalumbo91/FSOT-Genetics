FSOT β-STRAND-PAIR TRINARY COUPLING MAP (F17)
============================================================
Same format as 64_codon_trinary_map.txt and the 20 AA chemical map.
3 trits = 27 cells. Every coefficient closed-form in {π, e, φ, γ}.

Trit axes:
  D  Direction        −1=antiparallel    0=no register     +1=parallel
  R  Register offset  −1=Δ negative      0=in register     +1=Δ positive
  P  Pleat face       −1=opposite face   0=H-bond face     +1=same face

Multiplier rule (D ≠ 0):
  m(D, R, P) = φ ^ ((1 − |R|) + (1 − |P|) − 1)
For D = 0 (no register match): m = 1 / φ²  (suppress)
For continuous offsets |Δ| > 1: extra factor φ^(−|Δ|/π)

Note: φ ≈ 1.6180, φ² ≈ 2.6180, 1/φ ≈ 0.6180, 1/φ² ≈ 0.3820

DERIVATION OF AXES
------------------------------------------------------------
D — Direction trit
  In a β-sheet two strands run either antiparallel (most common, lowest
  energy, all H-bonds aligned perpendicular) or parallel (slightly higher
  energy, H-bonds tilted). FSOT trinary collapse: pick the direction
  whose Δ (offset from ideal register) is smaller; if BOTH directions are
  off by more than half the shorter strand, the trit collapses to 0 (no
  coherent pairing exists between the two regions).

R — Register trit
  Two β-strands H-bond at a unique register: residue i ↔ partner j*.
  Antiparallel:  j* = e_B − (i − s_A)
  Parallel:      j* = s_B + (i − s_A)
  Δ = j − j*.  Sign of Δ ⇒ R. |Δ| > 1 contributes the continuous decay
  φ^(−|Δ|/π) on top of the trit multiplier.

P — Pleat face trit
  Adjacent residues on one strand have side chains alternating UP/DOWN
  (the β-pleat). For an in-register H-bond pair both backbone NH/CO point
  inward — that is P = 0. Pairs whose side chains point the SAME way
  across strands (sterically packed) are P = +1. Pairs facing opposite
  ways (no contact possible) are P = −1.
  Antiparallel pleat: P = +1 if (i − s_A + e_B − j) mod 2 == 0  else −1.
  Parallel pleat:     P = +1 if (i − s_A + j − s_B) mod 2 == 0  else −1.
  P = 0 is reserved for the in-register (|Δ|=0) H-bond pair — the trinary
  collapsed state where pleat face is geometrically dominated by H-bonds.

WHY φ (NO FREE PARAMETERS)
------------------------------------------------------------
Every multiplier is φ^n for n ∈ {-2, -1, 0, +1}. φ is the canonical FSOT
golden-mean scaling. The (1−|R|) + (1−|P|) − 1 form gives a clean lattice:
  perfect cell ([±1, 0, 0])  → φ
  one trit off                → 1
  two trits off               → 1/φ
  D collapsed                 → 1/φ²

The continuous decay rate 1/π matches F07 backbone exponent — same FSOT
seed used consistently across the geometric layers.

INTEGRATION POINT
------------------------------------------------------------
Used as multiplicative gate inside F13 (region-pair contact) when both
regions are Strand kind. Replaces the uniform "every-pair-equal" coupling
that was capping LR precision at 7-8% on β-containing proteins.
